# Security documentation

threesock is a small open-source project with one maintainer. These documents are sized to that: short, specific, and true. They are also what threesock's own documentation checks read when it scans itself.

| Document | Covers |
|---|---|
| [threat-model.md](threat-model.md) | What threesock protects, where untrusted input enters, threats and mitigations |
| [risk-register.md](risk-register.md) | Risks with likelihood, impact, owner, treatment and controls |
| [incident-response.md](incident-response.md) | Roles, severity, escalation, communication, scenario runbooks |
| [vulnerability-management.md](vulnerability-management.md) | Triage criteria and remediation deadlines |
| [access-management.md](access-management.md) | Onboarding, offboarding, access reviews, key rotation |
| [business-continuity.md](business-continuity.md) | Dependencies, fallbacks and recovery |
| [third-parties.md](third-parties.md) | Services and components threesock depends on |
| [../releasing.md](../releasing.md) | Releasing, rolling back and emergency changes |

To report a vulnerability, see [SECURITY.md](../../SECURITY.md).
